Featured Case Study

From Near-Zero Visibility to 36,200 Monthly Impressions

Adelaide property services company · Client of So Cloudy · Sep 2025 to Mar 2026

The WordPress site had no analytics, an unverified Search Console property and a homepage no-index issue that kept it out of Google. I ran a 6-month campaign covering keyword research, on-page SEO, technical SEO and suburb-level page expansion.

  • Fixed the homepage no-index issue and set up GSC, GA4, Tag Manager, Bing Webmaster Tools and IndexNow
  • Built 18 service pages and a suburb location page template with LocalBusiness schema
  • Restructured internal links into a hub-and-spoke site architecture
  • Improved Core Web Vitals and optimized the Google Business Profile

184 → 36,200Monthly impressions
